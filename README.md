# Task 2: Data Visualization and Storytelling

**Objective
The objective of this task is to analyze sales data and present the information clearly using data visualization and business insights.

** Tools Used
- Python
- Pydroid3
- Basic Python Lists
- Matplotlib (optional for visualization)

** Dataset
A sample monthly sales and profit dataset for 12 months was created directly in the Python program.

The dataset contains:
- Month
- Sales
- Profit

** Work Done
The Python program performs the following operations:

1. Displays monthly sales and profit data.
2. Calculates total sales.
3. Calculates total profit.
4. Finds the month with the highest sales.
5. Displays important business insights.
6. Provides a simple story about the sales performance.

** Key Insights
- Sales increased gradually during the year.
- December recorded the highest sales.
- Profit also increased along with sales.
- Overall business performance improved during the year.

** Output
The program displays:
- Monthly sales and profit
- Total sales
- Total profit
- Highest sales month
- Key business insights

** Conclusion
This task demonstrates how Python can be used to analyze sales data and communicate important business insights in a simple and understandable way.
